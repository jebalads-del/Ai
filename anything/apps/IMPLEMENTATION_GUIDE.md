## 🔧 الإعدادات المطلوبة

### 1. مفتاح OpenAI API (لإنشاء الصور)
أضف المفتاح في **Secrets** بأحد الأسماء التالية:
- `OPENAI_API_KEY` (مفضّل)
- `OPEN_API_KEY`

**كيفية الحصول على المفتاح:**
1. اذهب إلى https://platform.openai.com/api-keys
2. أنشئ مفتاح API جديد
3. انسخ المفتاح (يبدأ بـ `sk-`)
4. أضفه في Secrets

**ملاحظة:** تأكد من وجود رصيد كافٍ في حساب OpenAI

---

### 2. مفتاح Replicate API (لإنشاء الفيديو)
أضف المفتاح في **Secrets** باسم:
- `REPLICATE_API_TOKEN`

**كيفية الحصول على المفتاح:**
1. اذهب إلى https://replicate.com/account/api-tokens
2. أنشئ حساب جديد (إذا لم يكن لديك)
3. انسخ API Token
4. أضفه في Secrets

**ملاحظة:** Replicate يوفر رصيد مجاني للبدء

## 🐛 حل المشاكل الشائعة

### ❌ "مفتاح OpenAI API غير موجود"
**الحل:**
- تأكد من إضافة `OPENAI_API_KEY` في Secrets
- تأكد من عدم وجود مسافات زائدة في المفتاح

### ❌ "مفتاح OpenAI API غير صحيح"
**الحل:**
- تأكد من أن المفتاح يبدأ بـ `sk-`
- تأكد من نسخ المفتاح كاملاً بدون أخطاء

### ❌ "لقد استنفدت حد الاستخدام"
**الحل:**
- المستخدم وصل للحد المسموح (5 عمليات للخطة المجانية)
- يجب ترقية الخطة من تبويب "الاشتراك"

### ❌ "خطأ من OpenAI (401)"
**الحل:**
- المفتاح غير صالح أو منتهي
- أنشئ مفتاح جديد من OpenAI

### ❌ "خطأ من OpenAI (429)"
**الحل:**
- تجاوزت حد الطلبات (Rate Limit)
- انتظر دقيقة وحاول مرة أخرى

### ❌ "خطأ من OpenAI (insufficient_quota)"
**الحل:**
- لا يوجد رصيد كافٍ في حساب OpenAI
- أضف رصيد في https://platform.openai.com/account/billing

### ❌ الفيديو يستغرق وقتاً طويلاً
**الحل:**
- إنشاء الفيديو يستغرق 2-5 دقائق (طبيعي)
- إذا تجاوز 5 دقائق، سيظهر خطأ "انتهت المهلة"
- حاول مرة أخرى بوصف أبسط
