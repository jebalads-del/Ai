# 🚀 دليل البدء السريع

## خطوات سريعة للبدء

### 1️⃣ إضافة مفاتيح API

#### مفتاح OpenAI (للصور):
```
اسم المتغير: OPENAI_API_KEY
القيمة: sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

احصل عليه من: https://platform.openai.com/api-keys

#### مفتاح Replicate (للفيديو):
```
اسم المتغير: REPLICATE_API_TOKEN
القيمة: r8_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

احصل عليه من: https://replicate.com/account/api-tokens

---

### 2️⃣ اختبار سريع

اذهب إلى: `/test-generation`

اضغط "ابدأ الاختبار"

✅ إذا ظهرت صورة = كل شيء يعمل!

❌ إذا ظهر خطأ = راجع رسالة الخطأ

---

### 3️⃣ استخدام التطبيق

1. سجّل دخول: `/account/signin`
2. اذهب إلى Dashboard: `/dashboard`
3. اختر:
   - **إنشاء صور** → اكتب وصف → أنشئ
   - **إنشاء فيديو** → اكتب وصف → أنشئ

---

## 🐛 مشاكل شائعة

### "مفتاح OpenAI غير موجود"
→ أضف `OPENAI_API_KEY` في Secrets

### "لقد استنفدت حد الاستخدام"
→ ترقية الخطة من تبويب "الاشتراك"

### الفيديو يستغرق وقتاً طويلاً
→ طبيعي! الفيديو يحتاج 2-5 دقائق
